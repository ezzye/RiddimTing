Make your first beat

  1. Press Play. The starting groove uses recreated sounds. Audio starts after your click.
  2. Change it. Mute a track, choose a pad and tap the visible steps. Groups A–D share the same timeline. Try group B for bass and C for keys.
  3. Play notes. Open the Scale keyboard. Arm Record for live overdub; when stopped, recording begins with a count-in. Repeat and arpeggio are in Live tools.
  4. Build a song. Commit variation makes a scene with copied patterns. Add scene numbers to Song arrangement. Choose immediate, next-bar or pattern-end changes.
  5. Perform. Use mutes, solos, the fader, punch controls and performance LOOP. Live lock protects edits and lets you choose which controls stay available.
  6. Keep it. Save project keeps all nine sessions and samples in one JSON backup. Export audio makes a WAV. Save HTML includes the whole instrument and your music.

Share deliberately. Project and HTML backups contain all nine sessions and imported sounds. Use Share file, or download and attach the file yourself. Nothing is uploaded automatically. Check licences before sharing imported audio.

What is inside

Music structure9 sessions, 4 groups × 12 pads, up to 99 patterns per group, 99 scenes and 99 song positions. Step/live recording, velocity, probability, note duration, triplet grids, swing and undo/redo.
Sounds46 recreated synthesized presets; ten Supertone-style slots including three sirens. No factory soundbank, artist projects or manufacturer WAV packs are bundled.
SamplingAudio-file import, microphone/OS or internal-output capture, gain/threshold, input channels and selectable recording rates. Trim, reverse, crop with undo, equal/transient/live chopping and resampling.
Loops and stretchPhase-aligned loop muting, performance segment loops, loop/non-loop pitch-preserving stretch to BPM or bar targets. Extreme stretch can introduce artifacts.
Effects7 shared send effects, 12 reconstructed punch actions, output compressor/limiter, fader automation and selected-sound sidechain routing.
Ting configurationsFour original Night Shift presets. Ten processing primitives, ordered chains and handle/shake/LFO modulation. Import/export editable JSON. BUS and pitch/frequency-shifting algorithms are approximations.
MIDIWeb MIDI note input/output, pad channels/root notes, MIDI-only routing, transport and outgoing 24-pulse clock. Browser support varies; physical controllers still need device testing.
Export limitsWAV rendering supports up to 128 bars plus a three-second tail. Live capture uses the browser format, often WebM/Opus. Long arrangements can be captured live.

Use your own sound packs

Choose Import sounds for audio. In Ting, choose Custom FX & presets → Import config JSON. If a configuration names a sample file, import that file with the matching name. Manufacturer packs are available separately; their own terms apply. This project does not relicense them.

Install and play offline

Open the instrument over HTTPS. Use Chrome/Edge’s Install option, Safari’s Add to Dock, or your mobile browser’s Add to Home Screen where supported. Wait for “Ready offline” before disconnecting. Browser storage can be cleared, so download a backup. The single-file HTML is a portable alternative; direct file opening and permissions vary by browser.

Keys: Q W E / A S D / Z X C / V B N play the twelve pads. Space plays/pauses when focus is on the workspace; Esc stops; R arms recording; K toggles keys; 1–4 select groups; ⌘/Ctrl Z undoes.

Fidelity and verification

This is an independent functional recreation inspired by the EP–40 guide and Ting guide, with easier controls. It is not affiliated with Teenage Engineering and is not a certified 1:1 emulation.

Deterministic tests cover scene timing, loop recall, recording tempo changes, repeat, held duration, swing, crop undo and import safety. Generated-signal tests informed the engine. These checks do not establish sound quality, exact hardware DSP, live latency or ease of use for you. Real microphone, physical MIDI, mobile devices, native installation and controlled hardware listening remain owner checks. Background tabs or a locked device can throttle timing.
