# Contributing

Run `npm run build` and `npm test` with Node 22+. No dependencies are required.

Keep `app/` buildless and usable offline. Preserve project import validation, local storage behaviour, accessible controls, and the distinction between reconstructed and verified hardware behaviour. Add meaningful regression tests for timing, sound routing, data loss or import errors. Include browser steps for UI/audio changes.

Use original or clearly licensed assets. Do not commit manufacturer sample/config packs, recordings, saved user projects, credentials or account data. Contributions are made under the repository's MIT licence.
